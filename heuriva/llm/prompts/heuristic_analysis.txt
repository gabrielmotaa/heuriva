# INSTRUÇÕES DE ANÁLISE
Para cada heurística, você deve:

1. **Examine o HTML E O SCREENSHOT da página**
   - Use o screenshot para entender o layout, hierarquia visual e design
   - Analise os elementos HTML correspondentes para verificar a estrutura e semântica
   - O screenshot é a fonte principal para avaliar questões visuais (contraste, alinhamento, consistência)
   - O HTML fornece o contexto técnico (acessibilidade, tags estruturais, atributos)

2. **Identifique problemas ESPECÍFICOS e concretos**
   - Cite elementos visíveis na imagem ou reais do código HTML (ex: "botão vermelho no canto superior" ou "div.modal sem aria-label")
   - Use exemplos do contexto fornecido
   - Foque em problemas verificáveis na imagem e no código
   - Cada item de problema deve ser uma frase objetiva e independente

3. **Avalie o nível de conformidade**
   - **excellent**: Implementação exemplar, sem problemas identificáveis
   - **good**: Bem implementado com pequenos detalhes de melhoria
   - **fair**: Implementação básica funcional, mas com oportunidades claras de melhoria OU quando não é possível avaliar completamente apenas pelo HTML estático
   - **poor**: Problemas significativos que impactam a usabilidade
   - **critical**: Problemas graves que impedem ou prejudicam seriamente o uso

4. **Quando usar "fair" (regular)**
   - Quando a heurística NÃO é aplicável à página atual
   - Quando NÃO há evidências suficientes no HTML ou no screenshot para fazer uma avaliação
   - Quando a avaliação dependeria de comportamentos interativos não visíveis
   - Quando há implementação básica mas sem elementos notáveis para avaliar

5. **Forneça recomendações ACIONÁVEIS**
   - Sugira melhorias específicas de UI/UX e código
   - Seja construtivo e prático
   - Cada recomendação deve ser uma ação clara e independente
   - Se não há recomendações relevantes, deixe a lista vazia

6. **Calcule pontuação geral**
   - Baseie-se no conjunto de todas as heurísticas avaliadas
   - Considere que avaliações "fair" por falta de evidência não devem penalizar muito
   - Score de 0 a 10
